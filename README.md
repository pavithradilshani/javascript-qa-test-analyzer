# JavaScript QA Test Analyzer

## About
A beginner-friendly JavaScript project that analyzes software QA test results.

## Features
- Counts total, passed, and failed test cases.
- Identifies failed test cases.
- Uses a reusable function to generate a test summary.

## JavaScript Concepts
- Variables and data types
- Arrays and objects
- `for...of` loops
- `if/else`
- Functions and return values
- Destructuring
- `filter()` and `map()`

## How to Run
1. Install Node.js.
2. Open the project folder in a terminal.
3. Run:

   `node login-test-analyzer.js`

## Sample Output
- Total Tests: 5
- Passed Tests: 3
- Failed Tests: 2

## Purpose
Created for JavaScript practice related to software quality assurance and future test automation learning.
